# Student Performance Prediction

## Objective
Predict whether a student will pass or fail based on:

- Study Hours
- Attendance
- Previous Score

## Machine Learning Algorithm
Logistic Regression

## Dataset
The dataset contains student information including study hours, attendance percentage, previous scores, and final grades.

## Features Used
- Study_Hours
- Attendance
- Previous_Score

## Target Variable
Result
- Pass = 1
- Fail = 0

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Git
- GitHub

## How to Run

pip install -r requirements.txt

python train_model.py

## Output
- Accuracy Score
- Classification Report
- Saved Model (model.pkl)
